## Зачем нужен этот репозиторий

Мы строго соблюдаем NDA и не публикуем исходный код закрытых коммерческих систем наших заказчиков. Этот репозиторий создан как **открытый образец нашей инженерной культуры** — он показывает, как мы проектируем отказоустойчивые API и защищаем бизнес-логику от финансовых и репутационных потерь.

### Какие критические сценарии проверяет стенд:
1. **Валидный расчёт (`HTTP 200 OK`):** Проведение платежа, запись транзакции в реестр (`Live Ledger`) и консистентное обновление баланса с замером задержки (`latency_ms`).
2. **Гонка сети / Дубль платежа (`HTTP 409 CONFLICT`):** Защита от двойного списания при повторной отправке запроса с тем же заголовком `Idempotency-Key` (проверяется параллельными горутинами в Go).
3. **Антифрод и контроль лимитов (`HTTP 403 FORBIDDEN`):** Автоматическая блокировка транзакций свыше 500 000 ₽.
4. **AI-фильтр (`LLM SANITIZER` / `HTTP 422`):** Встроенная NLP-валидация комментариев платежа против Prompt Injection, SQL-инъекций и утечки API-ключей.

## Архитектура и стек

* **Backend Core (`main.py`):** Python + FastAPI — реальный REST API шлюза (`/api/v1/payments/process`, `/api/v1/security/ai-sanitize`, `/api/v1/health/telemetry`) с контролем идемпотентности и in-memory реестром транзакций.
* **QA Concurrency Engine (`gateway_test.go`):** Многопоточные интеграционные тесты на **Go (Golang)**. Используют горутины для одновременной отправки конкурирующих запросов и проверки потокобезопасности.
* **Frontend Sandbox (`static/index.html`):** Адаптивный интерфейс терминала и консоли инспектора на чистом HTML/CSS/JS без тяжёлых зависимостей.
* **CI/CD (`.github/workflows/ci.yml`):** Автоматический прогон автотестов при каждом коммите.

### Почему монолитный `static/index.html` без зависимостей и комментариев?
Фронтенд-часть стенда намеренно реализована как **единый самодостаточный файл без бандлеров (`npm`/`webpack`), внешних библиотек и избыточного комментирования**:
* **Мгновенный деплой и ноль уязвимостей:** интерфейс отдаётся напрямую сервером FastAPI без установки сотен сторонних `node_modules` и рисков supply-chain атак.
* **Максимальная скорость отклика:** минимальный размер файла обеспечивает моментальную загрузку терминала и плавный вывод логов инспектора в реальном времени.
* **Самодокументируемая структура:** логика интерфейса построена декларативно вокруг 4 тестовых сценариев и легко читается без перегрузки комментариями, так как вся бизнес-валидация и безопасность изолированы на стороне бэкенда и в тестах `gateway_test.go`.

## Быстрый запуск

1. Запуск сервера FastAPI и веб-интерфейса:
```bash
py -m pip install -r requirements.txt
py -m uvicorn main:app --reload
```
Стенд откроется по адресу `http://127.0.0.1:8000` (интерактивный Swagger UI доступен на `/docs`).

2. Запуск многопоточных автотестов на Go (во втором окне терминала):
```bash
go test -v -race ./...
```
